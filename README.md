# bridge-for-codex Homebrew Tap

Official Homebrew Tap for [`bridge-for-codex`](https://github.com/bridge-for-codex) tools.

## Install `jcode-mcp`

```bash
brew install bridge-for-codex/tap/jcode-mcp
```

Or tap first so `brew search jcode-mcp` finds it directly:

```bash
brew tap bridge-for-codex/tap
brew install jcode-mcp
```

## Uninstall

```bash
brew uninstall jcode-mcp
```
